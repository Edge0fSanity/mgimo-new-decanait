# Источник истины и Git

Документы управления редактируются в Google Docs; локальные Markdown — проверенные снимки. Код, миграции, тесты и evidence хранятся в отдельном локальном Git-репозитории папки Деканат.

Настраиваемый здесь режим — ручной Google Docs → Git через подключённого агента. Первичная выгрузка проверяется чтением, ID/хеши фиксируются в .sync/manifest.json, изменения — локальным коммитом.

Remote, GitHub/GitVerse, CI/CD, автосync, расписание, хостинг и автоматический мониторинг не настроены.

Повторный sync: сверить локальный SHA-256 с manifest; при локальном изменении остановить файл. Прочитать Doc/revisionId, экспортировать во временный файл, снова проверить revisionId и локальную сумму, только затем заменить локальный снимок, обновить manifest, проверить diff и сделать commit.

При конфликте сохранить обе версии в .sync/conflicts/ и согласовать слияние. Правки Docs только с requiredRevisionId. Удаления не распространять, локальные изменения не отправлять автоматически, .env/пароли/ключи не включать.

Существующий DOCX не перезаписывать. Обратное автоматическое слияние и rclone не установлены.
