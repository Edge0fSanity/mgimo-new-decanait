# Ревью администрирования — принятые задачи (20.11.2026)

Решение по итогам ревью: делаем рабочий пример — основные данные (расписание, справочники, студенты, дедлайны, объявления, оценки) вводятся через Django Admin; отдельный кабинет сотрудника не строим. Интеграция с 1С вуза (или иной внешней системой) не разрабатывается — оставляем архитектурное место (T14). Все задачи TODO.
