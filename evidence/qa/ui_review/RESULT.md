# Повторная проверка студенческого интерфейса

18 ноября 2026, МСК. Доработка A03 по [ревью](../../../docs/UI_UX_REVIEW.md). Владелец кода и интеграции — основной агент Codex. Независимые проверяющие — `code_review` и `ux_review`. Основа сравнения — `dfdaa8f`, результат — рабочая копия. Среда — Django 5.2.19, отдельная SQLite с фиктивными студентами A/B, Chromium 156.0.8078.4 через Playwright, локальная сеть.

| Проверка | Результат в проверенном объёме |
|---|---|
| D-Q01 · D-R01 | Неверный пароль даёт сообщение об ошибке. После входа по ссылке на закрытый дневной экран браузер возвращается к выбранному расписанию. |
| D-Q02 · D-R02/07 | В сводке видны московская дата, группа, новое время и новая аудитория, прежние значения переноса. В расписании работают день, неделя и переход к текущему дню с переносом фокуса. Подтверждены пустой день, переход к паре следующей недели и московская полночь при активной зоне UTC. |
| D-Q03 · D-R03 | На A различимы долг, зачёт и «Оценка 5». Зачёт показан один раз, источник вынесен в подпись. У B отсутствующая оценка обозначена текстовым статусом. |
| D-Q04 · D-R04/05 | Обе формы отправляются, ошибка пустого поля видна рядом с ним. Номер справки совпадает в деталях и списке. После действия сотрудника доступны готовый HTML-образец и причина отклонения. |
| D-Q05 · D-R06/07 | Со сводки открываются дедлайны и активная заявка. Уведомление ведёт к заявке, отметка прочтения остаётся после обновления. |
| D-Q06 · D-R05 | Готовый образец доступен владельцу. Другой студент получает 404, анонимный посетитель перенаправляется на вход. Владелец также получает 404, пока образец по новой заявке ещё не готов. |
| D-Q08 · D-R08 | При 360/390/768/1440 px проверены навигация и отсутствие горизонтального скролла. Проверены поля, ошибки, фокус в шапке и на тёмной карточке, скролл к полям и кнопкам при уменьшенной высоте 360×420 px. Экранная клавиатура физического телефона остаётся вне этого прогона. |

Проверки Django выполнялись через `.venv/bin/python manage.py`. `test tests` прошёл 28/28, `check` — без замечаний, `makemigrations --check --dry-run` — без новых миграций. `git diff --check` прошёл.

## Независимые ревью

- Код. Отклонение ограничено заявками, явно отмеченными на странице. Исправлены согласованность истории при одновременных сменах статуса, московская дата, ссылка на неделю занятия и отображение причины отклонения. Повторный прогон пяти сценариев на SQLite прошёл, включая откат статуса при ошибке записи уведомления.
- UI/UX. Проверяющий прошёл 11 страниц на четырёх ширинах. После исправлений подтвердил доступность действий над списком заявок, приоритет перехода из уведомления, контраст фокуса и переход в неделю ближайшей пары.
