# Обязательная цепочка доказательств

Идея и проблема студентов → пользовательские сценарии → ранний дизайн → первый рабочий вход → заявки/сохранение → оценки/расписание → уведомления/документы → мобильность → проверка изоляции → развёртывание → тест из РФ → финальная версия.

На каждом этапе сохранять удачные и неудачные попытки. Не заменять ранние снимки финальными с выдуманной датой.

Для настоящих опросов указать n, способ набора, даты и ограничения; не публиковать персональные ответы. При отсутствии опроса честно обосновать функции условием конкурса и гипотезами команды.

В документ для жюри войдут полный перечень AI-инструментов/IDE/сервисов для кода, дизайна, текста и картинок; ключевые промпты; скриншоты; описание auth/хранения/защиты простыми словами; ручные шаги.

Скрытые внутренние рассуждения не сохранять; достаточно видимых поручений, ответов, результатов и проверок.
