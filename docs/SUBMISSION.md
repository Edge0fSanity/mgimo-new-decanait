# Проверка перед отправкой

Отдельная сессия жюри: доступ к прототипу, коду/архиву и описанию; вход обоими аккаунтами, создание заявки, изоляция, мобильность и РФ без VPN.

Сборка совпадает с исходниками и видео. Секреты/тестовые пароли отсутствуют в репозитории; конкурсные пароли передаются через нужное поле подачи, не публикуются в общих документах.

Записать время, капитана, ID/подтверждение отправки, ссылки, commit/хеш, версию описания. Подтверждение проверить после замены работы.

Разрешения папок не расширять целиком ради одного файла; доступ жюри проверять на конкретных материалах.
